# Domus Cultura — Vivid House logo family

20 coordinated directions. Every direction includes:

- full-colour SVG and transparent 3600 × 1800 PNG with 600-DPI metadata;
- pure black-and-white SVG and transparent 600-DPI PNG;
- grayscale SVG and transparent 600-DPI PNG.

The lettering remains unobstructed in all variants. SVG typography should be converted to outlines after a final mark is selected and before sending production files to a supplier. Test embroidery, screen printing and small-format legibility physically before launch.
