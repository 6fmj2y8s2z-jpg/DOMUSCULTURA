# Juice+ — independent DJ website

This folder is a self-contained static landing page. It does not depend on the Domus Cultura styles, scripts or asset paths.

## Deploy independently

- Create a new GitHub repository for this folder when the final domain is chosen.
- In Vercel, create a new project and select `juice-plus-site` as the Root Directory.
- Add the final DJ domain to that Vercel project only.
- Replace `hello@domuscultura.ch` if Juice+ receives a dedicated booking email.

The booking form prepares an email in the visitor's email application. It does not send or store personal information automatically.
