# Ben Taleb — independent artist website

This folder is a self-contained static website. It does not depend on the Domus Cultura styles, scripts or asset paths.

## Deploy independently

- Create a new GitHub repository for this folder when the final domain is chosen.
- In Vercel, create a new project and select `ben-taleb-site` as the Root Directory.
- Add the final artist domain to that Vercel project only.
- Replace `hello@domuscultura.ch` if Ben Taleb receives a dedicated studio email.

The current web images are previews. Replace them with properly licensed, high-resolution web exports before the final public launch.
